# Backend Hackaton2

## Instalación

```bash
cd backend
npm install
```

## Ejecución

```bash
npm start
```

## Endpoints

- `POST /api/login` — Login, devuelve un token JWT
- `GET /api/data` — Datos protegidos, requiere token
- `POST /api/data` — Agregar dato, requiere token
