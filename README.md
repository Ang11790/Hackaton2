# Web App Template (React + TypeScript + Express)

Estructura:
- frontend/  -> React + TypeScript + Bootstrap (plantilla)
- backend/   -> Node + Express (API fake: login + CRUD)
- docs/      -> Notas y profundización

Instrucciones rápidas:

1. Backend
   cd backend
   npm install
   node server.js

2. Frontend
   cd frontend
   npm install
   npm start

(El frontend está pensado para crearse con Create React App + TypeScript si prefieres; aquí hay archivos base para copiar al proyecto).
